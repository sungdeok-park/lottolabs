# 로또 워크룸 (개발 중)

내 필터로 로또 6/45 조합을 만들고, 저장·공유한 뒤 추첨 결과까지 확인하는 정적 웹 도구.
당첨을 예측하거나 보장하지 않는다. 기획: `LOTTO-CONTENT-DIFFERENTIATION-PLAN.md`.

## 실행

```
npm install
npm run dev        # 개발 서버
npm test           # 계산 엔진 시험 (전체 8,145,060 열거 포함)
npm run build      # 타입 검사 + 정적 빌드(dist/)
```

## 당첨 이력 데이터

`public/data/draws.json`은 **비어 있다**(실제 데이터를 임의로 만들지 않음). 검증된 출처의 CSV를 준비해 넣는다.

```
node scripts/import-draws.mjs draws.csv "출처 설명"   # 열: round,date,n1..n6,bonus
```

검증에 실패하면 기존 파일을 유지한다. 데이터 공급 경로와 사용 조건은 출시 전에 확인해야 한다.

## 구현 범위 (1차)

- 계산 엔진 `src/core`: 필터 19종, 생성(고정/제외/후보·시도 상한·취소·중복 제거), 정확한 조합 수 열거, 등수 대조, 당첨 파일 검증, 공유 payload 검증
- 화면: 홈, 조합(번호판·필터·통계·프리셋), 보관함(대조·복사·메일·CSV/TXT/JSON·가져오기·백업/복원), 공유 보기, 도움말
- 저장: IndexedDB(불가 시 메모리 대체 + 경고)

## 미구현 / 확인 필요

- 카카오톡 전용 공유(Kakao 앱·JS 키·도메인 등록 필요, 현재는 OS 공유로 대체)
- 원본(lottoanalysis) 필터 동등성: 용지·마방진·회귀·핫콜드·커스텀 번호 집합·표현식 필터, 이웃수·이월수는 이 저장소 정의 기준
- Web Worker 분리, 생성 개수 상한(현재 임시 500) 성능 시험, PWA, 운영자 제외수, 광고, 해설 콘텐츠 페이지
- 실기기(모바일 공유·mailto 길이) 시험
